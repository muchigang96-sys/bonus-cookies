# BONUS Cookies

Учебный сайт каталога печенья. HTML, CSS и JavaScript без сборки и сторонних библиотек.

## Запуск

Откройте `index.html` в браузере.

## Возможности

- Каталог из 12 товаров.
- Навигация по разделам.
- Переключение валюты по заданным демонстрационным коэффициентам.
- Проверка заполнения формы заказа.

Форма демонстрационная: данные никуда не отправляются, после заполнения появляется уведомление.

## Структура

- `index.html` — разметка.
- `styles/styles.css` — оформление.
- `scripts/script.js` — интерактивность.
- `images/` — изображения.
- `fonts/` — шрифты.
